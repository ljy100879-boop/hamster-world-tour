| 폴더 | 출처 | 라이선스 |

| `icons/` | Microsoft Fluent Emoji (3D) — https://github.com/microsoft/fluentui-emoji | MIT, Copyright (c) Microsoft Corporation |

| `hamsters/` | 사용자가 직접 생성한 이미지 (없으면 게임 내장 SVG 사용) | - |

## 배경 세계지도
- `assets/background/world-map.svg` — [Natural Earth](https://www.naturalearthdata.com/) 1:110m 육지 데이터로 `tools/make_world_map.py` 가 생성. 퍼블릭 도메인.

## 시작 화면 제목 폰트
- 메이플스토리 Bold — 넥슨 무료 폰트(상업적 이용 가능), jsDelivr의 눈누(projectnoonnu) 배포본을 웹폰트로 불러옴. 불러오지 못하면 Jua 로 표시.
