## 1. 게임 개요

### 1.1 한 줄 소개
골든 햄스터들이 세계 수도를 여행하며 땅을 사고, 건물을 짓고, 통행료를 받아 상대를 파산시키는 혼자 놀기용 부동산 보드게임. 주사위와 카드마다 **수학·한국사·상식 문제**를 풀어야 진행된다.

### 1.2 목표
- 모노폴리 클래식 규칙을 따라, 규칙을 아는 사람은 설명 없이 바로 플레이
- 컴퓨터 상대가 그럴듯하게 플레이해 혼자서도 긴장감 있는 한 판
- 햄스터 캐릭터와 연출로 "귀여움"을 차별점으로
- 게임 진행 안에서 초등 연산, 중학교 수준 한국사, 상식 문제를 반복 학습

### 1.3 대상
- 초등학생 (사칙연산 문제), 중학교 수준 한국사·상식에 도전하는 어린이
- 모노폴리를 알고 혼자 가볍게 한 판(30~60분) 즐기려는 사용자

### 1.4 범위 밖 (Non-goals)
- 온라인 멀티플레이 / 로컬 다인 플레이(핫시트)
- 계정, 랭킹, 결제

## 2. 핵심 게임 루프

1. 시작 화면에서 내 햄스터·컴퓨터 수·난이도 선택 (UI-001)
2. 내 차례: 굴리기 버튼을 꾹 눌렀다 뗌 (REQ-010) → **수학 문제** (REQ-080) → 맞히면 그 답만큼 이동
3. 도착 칸 효과: 구매/경매, 통행료→강제 매입, 내 땅 건설, 카드 문제, 텔레포트, 세금, 케이지 (SYS-003~SYS-009)
4. 건설·저당·거래 후 턴 종료 (할 일이 없으면 자동 종료, REQ-015)
5. 5바퀴마다 세계 이벤트 (REQ-120)
6. 마지막 생존자(또는 턴 제한 시 총자산 1위)가 승리 → 승리/패배 연출 (REQ-140)

### SYS-002 턴 진행 · 주사위
- **REQ-010** 굴리기: 보드 가운데 주사위 아래 버튼(또는 스페이스바)을 **꾹 눌렀다 떼면** 던짐. 누르는 동안 힘 게이지가 0→100→0으로 약 1.1초 주기로 오르내리며, 뗀 순간의 힘(최소 12%)은 던지는 모습에만 영향을 준다(눈은 무작위). Enter·클릭은 보통 힘. 버튼 글자: "꾹 눌러 굴리기" / "꾹 눌러 한 번 더!" / "꾹 눌러 더블 노리기".
- **REQ-011** 주사위를 던지기 전에 수학 문제를 맞혀야 한다 (REQ-080~085).
- **REQ-012** 합만큼 시계 방향 이동. 출발 칸을 지나거나 도착하면 🌻200.
- **REQ-013** 더블이면 한 번 더 굴림. 3연속 더블이면 즉시 케이지. 케이지에서 더블로 탈출하면 추가 굴림 없음. 주사위 아래에 결과("🎲 3 + 3 = 6 · 더블!")와 다시 굴리지 않는 더블의 이유를 표시.
- **REQ-014** 순서는 시작 시 주사위를 굴려 높은 순.
- **REQ-015** 자동 턴 넘기기: 굴린 뒤이고, 더블 재굴림·구매 결정·빚·경매·받은 거래 제안·카드 문제가 없고, 지금 지을 수 있는 건물과 해제할 수 있는 저당이 없고, 창을 열어 두지 않았으면 1.5초(빨리 감기 0.5초) 진행 막대 후 자동 종료. [바로 넘기기 ✔] / [잠깐 멈추기 ✋] 제공.

### SYS-003 부동산 경제
- **REQ-020** 시작 자금 🌻1,500. 은행 건물 재고: 햄스터 굴 32채, 햄스터 궁전 12채.
- **REQ-021** 주인 없는 칸 도착 → 정가 구매 또는 거절. 거절하면 즉시 경매(모든 플레이어, 현재 플레이어부터 돌아가며 입찰/포기, 포기하면 재참여 불가, 최고 입찰자만 남으면 낙찰).
- **REQ-022** 남의 칸 도착 → 통행료 지불(저당 잡힌 땅은 통행료 없음). 통행료 = 기본 통행료 × 세계 이벤트 배율(REQ-121), 반올림.
- **REQ-023** 독점: 같은 색 그룹을 모두 소유하면 건물 없는 칸의 기본 통행료 2배.
- **REQ-024** "내 땅 관리"로 짓기: 독점 그룹에서 **균등 건설**(칸 사이 차이 ≤1), 그룹에 저당 칸이 있으면 불가, 굴 4채 → 궁전 1채(굴 4채 반납 + 건설비 1회), 은행 재고가 없으면 불가.
- **REQ-025** 건물 매각은 건설비의 50% 환급, 균등하게 매각. 은행 굴이 4채 미만일 때 궁전 매각은 궁전을 통째로 팔고 굴 5채 값의 절반 환급.
- **REQ-026** 저당: 저당가 수령, 해제 시 저당가 + 10%. 건물이 있는 그룹의 칸은 저당 불가.
- **REQ-027** 저당 잡힌 땅을 거래·파산으로 받으면 이자 10%를 자동으로 내고 저당 상태로 받는다.
- **REQ-028** 총자산 = 현금 + 땅값(저당 땅은 땅값 − 저당가) + 건물 건설비.
- **REQ-029** 사람의 건설·매각·저당은 게임 중 언제든(컴퓨터 턴 중에도). 컴퓨터는 자기 턴 주사위 전·후에만.

### SYS-008 학습 문제
**주사위 수학 문제**
- **REQ-080** 사람이 굴리면(시작·더블 재굴림·케이지 더블 노리기 모두) 주사위가 던져지기 전에 문제 창이 뜬다. 컴퓨터는 문제를 풀지 않는다.
- **REQ-081** **정답 = 이번에 굴러갈 주사위 두 개의 합 (2~12)**. 엔진 `peekDice`가 시드를 바꾸지 않고 미리 보며, 맞힌 뒤 실제로 같은 숫자가 나온다. 보기 3개(정답 근처 2~12), 제한 시간 15초(마지막 5초 빨강), 키보드 1·2·3 가능.
- **REQ-082** 난이도는 시작 화면의 컴퓨터 난이도를 따른다.

| 난이도 | 문제 종류 |
|---|---|
| 쉬움 | 한 자리 수 덧셈·뺄셈 |
| 보통 | 덧셈·뺄셈(두 자리 수 포함) + 곱셈(구구단) |
| 어려움 | 사칙연산 모두 + 두 단계 계산 (예: `24 ÷ 3 − 1`) |

  정답에 맞는 식을 만들 수 없으면 같은 난이도의 다른 종류로 낸다.
- **REQ-083** 맞히면 "딩동댕! 🎲 N칸!" 후 꾹 눌렀던 힘 그대로 굴러간다.
- **REQ-084** 틀리거나 시간 초과 → 정답은 알려 주지 않고(답이 같으므로) 다른 식의 새 문제. 남은 기회 ❤️ 표시.
- **REQ-085** **3번째로 틀리면** 정답을 보여 주고 이번 굴리기 기회를 잃는다(엔진 `forfeitRoll`, 난수 소모 없음): 굴린 것으로 치고 턴 마무리 단계로. 더블 재굴림에서는 추가 굴림만 잃는다. 케이지에서는 탈출 시도 1회로 치되 최대 2까지만 센다(3번째 시도는 직접 굴려야 함).

**카드 문제**
- **REQ-090** 찬스 칸 → **한국사**(중학교 수준), 볼주머니 칸 → **상식**. 문제 은행 `js/questions.js` (현재 한국사 46, 상식 46). 다 나올 때까지 겹치지 않게 섞어서 낸다.
- **REQ-091** 문제 창에 이번에 나올 카드를 먼저 보여 준다("😊 좋은 카드" / "😈 나쁜 카드" + 카드 내용). 보기 3개, 15초.
- **REQ-092** 결과 규칙

| | 맞힘 | 틀림 · 시간 초과 |
|---|---|---|
| 좋은 카드 (공격 카드 포함) | 발동 | 무효 |
| 나쁜 카드 | 피함 (무효) | 발동 |

- **REQ-093** 틀리면 정답을 보여 준다. 쓰지 않은 카드(무효·피함)는 덱 맨 아래로. 피하면 "휴~ 피했다! 😌", 무효면 "카드 무효… 😢".
- **REQ-094** 카드 효과로 다른 찬스·볼주머니 칸에 도착하면 다시 문제. 카드가 다른 카드를 뽑게 하면(c29, h27) 문제 없이 바로 뽑는다.

### SYS-009 특수 규칙
- **REQ-100 텔레포트(20번 칸)**: 도착하면 보드 칸을 눌러 원하는 칸으로 순간이동(확인 창에 빈 땅/내 땅/남의 땅 통행료/케이지 경고 안내), "그대로 있기" 가능. 이동한 칸의 효과 적용. 20번보다 앞 번호 칸으로 가면 출발 통과(🌻200, 0번에 정확히 도착하면 옵션 REQ-151 적용). 옵션 상금(REQ-150)은 받고 텔레포트.
- **REQ-101 내 땅 건설**: 내 도시(공항·공공시설 제외)에 도착하면 "건물을 지을까요?" 창 — 건설비와 통행료 변화(예: 🌻4 → 🌻20) 표시. 같은 색을 다 갖지 않아도, 균등 규칙 없이 도착할 때마다 한 단계. 저당 중·재고 없음·돈 부족이면 불가.
- **REQ-102 강제 매입**: 남의 칸에서 통행료를 다 낸 뒤, 궁전이 없고 저당이 아닌 땅이면 "강제로 사 버릴까요?" 창. **매입가 = (땅값 + 지은 건물 공사비) × 1.2, 10 단위 올림**. 매입가는 원래 주인에게, 건물도 함께 넘어온다. 빚이 생겼거나 매입가만큼 돈이 없으면 제안 없음.
- **REQ-120 세계 이벤트**: 5·10·15…바퀴가 시작될 때 시드 난수로 하나 발생, 큰 카드로 발표.
- **REQ-121** 세계 이벤트 종류

| 종류 | 효과 | 지속 |
|---|---|---|
| 📈 부동산 폭등 | 모든 통행료 ×1.5 | 다음 세계 이벤트까지 |
| 📉 부동산 폭락 | 모든 통행료 ×0.5 | 다음 세계 이벤트까지 |
| 🎉 축제 개막 | 무작위 색깔 그룹 통행료 ×2 (칸이 반짝임) | 다음 세계 이벤트까지 |
| 🌾 해바라기 풍년 | 모든 햄스터 🌻100 받기 | 즉시 |
| 🥀 흉년 | 모든 햄스터 은행에 🌻50 (모자라면 현금 마련/파산) | 즉시 |

## 5. UI/UX 요구사항
- **UI-001 시작 화면**: 화면 가득 반투명(38%) 세계지도 배경 위 설정 카드. 4마리 햄스터 일러스트, 제목 "햄스터 월드 투어"(메이플스토리 Bold 웹폰트, 꿀 노랑 #ffd43b + 초코 테두리·그림자 #7a3f0c, 화면 폭에 맞춰 한 줄), 내 햄스터 선택, 내 이름(최대 8자), 컴퓨터 수 1~3, 난이도, 추가 규칙, 게임 시작 / 이어하기.
- **UI-002 배경**: 시작·게임 화면 모두 화면 전체에 세계지도(Natural Earth로 만든 `assets/background/world-map.svg`) + 대륙 위 햄스터 8마리 + 점선 여행 경로, 불투명도 38%, 눌리지 않음. `assets/background/bg.png`가 있으면 그 그림으로 대체.
- **UI-003 게임 화면 배치**: 왼쪽 보드는 화면 높이에 꽉 차게, 넓은 화면에서 가로 최대 1.45배까지 늘어나는 직사각형(900px 이하 정사각형). 오른쪽 끝 패널: 도구 모음(🏠 내 땅 관리, 🤝 거래, ⏩ 빨리 감기, 🎵 배경음악, 🔊 효과음, ☰ 메뉴) / 플레이어 카드 / 할 일 / 게임 기록. 보드 안 크기는 보드 가로·세로 평균의 1% 단위.
- **UI-004 칸 표시**: 소유한 칸은 바탕이 주인 햄스터 색(52%)으로 물듦, 저당은 바랜 색 + "저당" 도장. 주인이 있는 칸(공공시설 제외)은 가격 대신 지금 통행료("통행 🌻20", 오르면 주황·내리면 파랑). 축제 그룹 칸은 반짝임. 텔레포트 고르는 동안 모든 칸이 보랏빛으로 반짝임.
- **UI-005 보드 가운데**: 제목, 주사위, 힘 게이지, 결과 글자, 굴리기 버튼(젤리 사탕 모양, 사람이 굴릴 수 있을 때만), 바퀴 수·은행 재고·현재 세계 이벤트·다음 세계 이벤트 바퀴, 카드 더미, 해바라기씨 장식(불투명도 42%, 고정).
- **UI-006 창(모달)**: 구매, 경매, 건설 제안, 강제 매입, 공격 대상, 거래 제안, 빚, 카드 공개, 세계 이벤트, 수학/카드 문제, 텔레포트 확인, 결과. 칸을 누르면 상세 카드(국기·랜드마크·통행료 표·주인·건물).
- **UI-007 휴대폰(900px 이하)**: 보드는 화면 위, 패널(도구 모음 → 할 일 → 플레이어 카드 2열 → 게임 기록)은 화면 아래에 고정된 **하단 시트**. 접힌 시트는 보드 아래 남는 높이(최소 200px)를 차지해 보드를 가리지 않고, 시트 안에서 스크롤. 위쪽 손잡이를 누르면 화면 높이의 82%까지 펼침/접기. 창(모달)은 시트 위에 뜬다. 가로 스크롤 없음.

## 7. 시스템 의존성
- 스크립트 로드 순서: `data → engine → ai → questions → hamster → sound → ui` (ES 모듈 없음, `file://`에서도 실행)
- `data.js`, `engine.js`, `ai.js`, `questions.js`는 Node에서도 실행 (`tests/`)
- 엔진은 DOM을 쓰지 않고 `s.events`로 연출 이벤트만 쌓는다. 화면 `pump()`가 이벤트를 재생하고 컴퓨터 행동을 진행한다.
- 게임 결과에 영향을 주는 난수는 모두 시드 난수(`Engine.rand`). 화면 전용(문제 출제·장식)만 `Math.random`.
- 외부 의존: Google Fonts(Jua, Gowun Dodum, Noto Color Emoji), jsDelivr의 메이플스토리 웹폰트. 불러오지 못하면 대체 글꼴.
- 엔진 훅: `Engine.hooks.raiseCash`, `Engine.hooks.evaluateTrade` (ai.js가 등록)

## 8. 비기능 요구사항
- **NFR-001** 정적 웹 앱(HTML/CSS/JavaScript), 빌드·서버 없음, `index.html`을 직접 열어도 동작.
- **NFR-002** 규칙(엔진)과 화면 분리, 엔진은 자동 테스트 가능.
- **NFR-003** 컴퓨터끼리 100판 자동 시뮬레이션에서 크래시·멈춤·불변식 위반 0건 (`node tests/sim.js 100`). 20,000걸음 제한에 걸린 판은 실패로 보지 않는다.
- **NFR-004** 새로고침 후 이어하기 시 상태 완전 복원. 상태 모양을 바꾸면 옛 저장과의 호환을 고려.
- **NFR-005** 목표: 60fps 애니메이션, 초기 로딩 2초 이내 (측정한 적 없음 — 목표치).
- **NFR-006** PC와 휴대폰 폭(390px)에서 가로 스크롤 없이 표시.
