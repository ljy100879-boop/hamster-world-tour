# BUG-003 — 보드 가운데 제목이 위쪽 칸에 걸쳐 보임

- 발견일: 2026-11-02 (사용자 신고: 스크린샷 — "햄스터 월드 투어라는 글자가 살짝 게임판에 걸쳐져 보여")
- 상태: **Fixed** (CHG-037)
- 관련 요구사항: UI-003, UI-005
- 심각도: 낮음 (보기 문제, 진행 영향 없음)

## 현상
넓은 화면에서 보드 가운데 내용(제목 · 주사위 · 결과 · 굴리기 버튼 · 정보 줄 · 카드 더미)이 가운데 칸보다 높아져 제목이 위쪽 줄 칸(로마~파리)에 걸치고, 아래쪽 카드 더미도 아래 줄에 닿는다.

## 재현과 측정
헤드리스 Chrome, 가장 긴 경우(세계 이벤트 표시 + 더블 결과 + 텔레포트 상금 줄)에서 가운데 칸 높이와 내용 높이(px):

| 화면 | 가운데 칸 | 내용 | 위로 넘침 | 아래로 넘침 |
|---|---|---|---|---|
| 1272×897 | 615 | 532 | - | - |
| 1280×720 | 521 | 493 | - | - |
| 1366×768 | 558 | 544 | - | - |
| 1400×850 | 620 | 575 | - | - |
| **1600×900** | 658 | 663 | **8** | - |
| **1920×1080** | 795 | 830 | **25** | **10** |
| 390×844 | 272 | 235 | - | - |

## 원인
보드 안 크기 단위 `--u`는 보드 **가로·세로 평균**의 1%(CHG-011). 넓은 화면에서는 보드가 가로로 최대 1.45배까지 늘어나므로, 세로로 쌓인 가운데 내용이 가로 폭에 비례해 커지지만 가운데 칸 높이는 세로에만 비례한다. CHG-030에서 가운데 정보에 2줄(현재 세계 이벤트, 다음 세계 이벤트)이 늘며 여유가 없어졌다.

## 해결
가운데 내용(`.center-inner`) 안에서만 단위를 `min(가로·세로 평균, 세로)`의 1%로 바꿔, 보드가 옆으로 넓어져도 가운데 내용은 보드 높이 기준으로만 커지게 한다. 정사각형 보드(900px 이하 포함)에서는 지금과 같다.

## 해결 기록
2026-11-02, CHG-037: `css/style.css` `.center-inner`에 `--u: min(calc((1cqw + 1cqh) / 2), 1cqh)`. 같은 측정 7개 화면에서 모두 넘침 없음 (아래 CHG-037 참고).
