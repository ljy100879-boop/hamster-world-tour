# BUG-002 — 눈을 깜빡일 때 햄스터 전체가 깜빡임

- 발견일: 2026-11-02 (사용자 신고: "눈을 깜빡일 때마다 캐릭터 전체가 깜빡여")
- 상태: **Fixed** (CHG-036)
- 관련 요구사항: REQ-130
- 도입: CHG-035 (눈 깜빡임 추가)
- 심각도: 중간 (눈에 띄는 깜빡임이 몇 초마다 반복)

## 현상
그림 햄스터가 눈을 깜빡일 때, 눈만 감았다 뜨는 것이 아니라 햄스터 전체가 순간 사라졌다가 흐릿하게 다시 나타난다.

## 재현과 측정
헤드리스 Chrome에서 한 마리에 `blinking`을 0.15초 붙였다 떼며 20~25ms마다 불투명도를 기록 (수정 전):

| 시각 | 기본 그림 | 감은 눈 그림 |
|---|---|---|
| 0~150ms (감음) | 0.00 | 1.00 |
| 151ms (뜸) | **0.00** | **0.00** ← 둘 다 안 보임 |
| 176ms | 0.07 | 0.00 |
| 226ms | 0.58 | 0.00 |
| 351ms | 1.00 | 0.00 |

## 원인
깜빡이는 동안 기본 그림(`.hb`)을 숨기고 감은 눈 그림을 보였다. 감은 눈 그림은 즉시 사라지지만, 기본 그림에는 원래 `.himg img { transition: opacity .2s }`가 걸려 있어 0에서 1로 0.2초 동안 서서히 돌아온다. 그 사이 햄스터 전체가 사라졌다 흐릿하게 나타난다.

## 해결
1. 기본 그림은 숨기지 않고 그대로 두고, 감은 눈 그림을 그 위에 겹쳐 보였다 감춘다 (전환 없음).
2. 겹치기만 하면 반투명한 윤곽 가장자리가 두 번 칠해져 깜빡일 때마다 **테두리가 1px 진해지는** 것이 픽셀 비교로 드러남 → 감은 눈 그림을 **눈 부분만 남기고 나머지는 투명**하게 다시 만듦 (`tools/make_blink.py`, 가장자리는 부드럽게).

## 해결 기록
2026-11-02, CHG-036
- `css/style.css`: 깜빡임 중 기본 그림(`.hb`)을 숨기던 규칙 삭제 → 불투명도 기록에서 기본 그림이 내내 1.00
- `tools/make_blink.py` + `assets/hamsters/*-blink.png` 4장 재생성: 눈 부분만 있는 겹침용 그림
- 눈 뜬/감은 상태 픽셀 비교: 1단계(겹치기만)에서는 바뀐 픽셀이 눈 + 몸 전체 윤곽(가로 12~87%, 세로 2~97%) → 2단계(눈 부분만 있는 그림) 후 눈 부분만(가로 30~71%, 세로 27~43%)
