# BUG-004 — 폭이 좁고 높이가 낮은 화면에서 하단 시트가 보드·굴리기 버튼을 가림

- 발견일: 2026-11-02 (전체 점검 중)
- 상태: **Fixed** (CHG-041)
- 관련 요구사항: UI-007
- 심각도: 중간 (해당 화면에서 굴리기 버튼이 처음엔 안 보임 — 화면을 내리면 보임)

## 현상
가로 900px 이하이면서 세로가 낮은 화면(예: 900×700, 휴대폰 가로 모드, 작은 태블릿 가로)에서 보드가 화면 높이보다 크게 그려지고, 하단 시트(최소 200px)가 보드 아래쪽과 가운데 굴리기 버튼을 덮는다.

## 재현과 측정 (헤드리스 Chrome)
| 화면 | 보드 아래 끝 | 시트 위 끝 | 굴리기 버튼 보임 |
|---|---|---|---|
| 360×640 | 350 | 364 | 예 |
| 768×1024 | 758 | 772 | 예 |
| **900×700** | **890** | **500** | **아니오** |

## 원인
`sizeBoard()`가 900px 이하에서는 보드를 **가로 폭에 맞춘 정사각형**으로만 정하고 화면 높이를 보지 않는다. 시트 높이는 `max(200px, 남는 높이)`라 남는 높이가 없으면 200px로 보드를 덮는다.

## 제안 해결
900px 이하에서 보드 크기 = `min(가로 폭, 화면 높이 − 시트 최소 높이 200 − 여백)` (단, 너무 작아지지 않게 하한, 예: 300px). 세로 화면(휴대폰 세로)은 지금과 같다.

## 해결 기록
2026-11-02, CHG-041: `sizeBoard()` 900px 이하에서 보드 = `min(가로 폭, 화면 높이 − 시트 최소 높이 − 24)`(하한 240), 시트 최소 높이는 화면 높이 560 미만이면 120px(그 외 200px). 재측정: 900×700 보드 476px · 시트 200px, 844×390 보드 246px · 시트 120px, 667×375 보드 240px · 시트 120px — 모두 보드·굴리기 버튼이 시트에 가리지 않음. 세로 휴대폰·태블릿(360×640, 390×844, 768×1024)은 이전과 같은 크기.
