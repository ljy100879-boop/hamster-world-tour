# BUG-005 — 태블릿 폭에서 말이 움직일 때 잠깐 가로 스크롤이 생김

- 발견일: 2026-11-02 (전체 점검 중)
- 상태: **Fixed** (CHG-041)
- 관련 요구사항: UI-007, NFR-006
- 심각도: 낮음 (몇 순간 2~3px 가로 스크롤)

## 현상
768×1024에서 오른쪽 줄 칸(31~39번)에 있는 말이 폴짝 뛰거나 표정이 바뀔 때 화면 오른쪽 끝을 2~3px 넘어 순간 가로 스크롤이 생긴다.

## 재현과 측정
헤드리스 Chrome 768×1024, 게임 시작 후 9초 동안 50ms마다 측정: 37번 `scrollWidth`가 770~771px(화면 768px). 넘친 요소는 `div.token`(오른쪽 끝 770~771px). 세계지도 배경은 고정·잘림 레이어 안이라 원인이 아님.

## 원인
900px 이하에서 보드가 화면 폭에 거의 꽉 차(좌우 여백 10px) 오른쪽 줄 말의 점프·확대 연출이 화면 밖으로 살짝 나간다.

## 제안 해결
페이지 가로 넘침을 잘라 내기(`body { overflow-x: clip }` — 스크롤 영역을 만들지 않음) 또는 보드 영역에서만 가로를 자르기.

## 해결 기록
2026-11-02, CHG-041: `html, body { overflow-x: clip }`. 재측정: 768×1024 등 10개 화면에서 게임 시작 후 6초 동안 50ms마다 감시 — 가로 넘침 0회 (수정 전 768×1024 37회).
