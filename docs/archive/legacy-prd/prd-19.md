## 1. 개요

### 1.1 한 줄 소개
귀여운 골든 햄스터들이 전 세계 수도를 여행하며 땅을 사고, 집을 짓고, 통행료를 받아 상대를 파산시키는 혼자 놀기용 보드게임.

### 1.2 목표
- 기존 모노폴리 룰을 그대로 따라, 룰을 아는 사람이라면 설명 없이 바로 플레이 가능
- 컴퓨터 상대가 충분히 그럴듯하게 플레이하여 혼자서도 긴장감 있는 한 판
- 햄스터 캐릭터와 애니메이션으로 "귀여움"을 핵심 차별점으로

### 1.3 범위 밖 (Non-goals)
- 온라인 멀티플레이 / 로컬 다인 플레이(핫시트)
- 계정, 랭킹, 결제
- 하우스 룰 기본 적용 (옵션으로만 고려, §9 참고)

## 2. 타깃 사용자 & 핵심 시나리오

- **타깃**: 모노폴리를 알고, 혼자 가볍게 한 판(30~60분) 즐기고 싶은 사용자
- **시나리오**
  1. 게임 시작 → 내 햄스터 선택, 컴퓨터 상대 수/난이도 선택
  2. 주사위를 굴려 이동 → 도시 구매 / 통행료 지불 / 카드 이벤트
  3. 같은 색 도시 독점 → 집·호텔 건설 → 컴퓨터에게 통행료 수금
  4. 컴퓨터와 거래·경매로 독점 완성
  5. 마지막 생존자가 승리 → 결과 화면

## 5. 게임 룰 (클래식 모노폴리 기준)

### 5.1 준비
- 각 플레이어 🌻1,500 지급, 모두 출발 칸에서 시작
- 순서는 주사위를 굴려 높은 순으로 결정
- 은행: 햄스터 굴 **32채**, 햄스터 궁전 **12채**로 한정

### 5.2 턴 진행
1. 주사위 2개 굴림 → 합만큼 시계 방향 이동
2. 도착 칸 처리 (§5.3)
3. 턴 중 언제든: 건설 / 매각 / 저당 / 저당 해제 / 거래 제안 가능
4. **더블**이면 한 번 더 굴림. **3연속 더블**이면 즉시 케이지로 이동
5. 출발 칸을 지나거나 도착하면 🌻200 수령

### 5.3 칸별 처리
| 칸 | 처리 |
|---|---|
| 주인 없는 도시/공항/시설 | 정가 구매 또는 거절. **거절 시 즉시 경매** (모든 플레이어 참여, 🌻1부터 시작) |
| 남의 소유 | 통행료 지불 (저당 잡힌 땅은 통행료 없음) |
| 내 소유 | 아무 일 없음 |
| 찬스 / 볼주머니 카드 | 덱 맨 위 카드 1장 실행 후 맨 아래로 (케이지 탈출권은 보유) |
| 소득세 / 사치세 | 각각 🌻200 / 🌻100 은행에 지불 |
| 톱밥 휴게소 | 아무 일 없음 (공식 룰) |
| 케이지로 가시오 | 출발 통과 없이 바로 케이지, 턴 종료 |

### 5.4 독점과 건설
- 같은 색 그룹을 **모두 소유**(저당 없음)하면 독점
- 독점 시 건물 없는 칸의 기본 통행료 **2배**
- **균등 건설**: 그룹 내 칸 사이 굴 개수 차이가 1을 넘을 수 없음 (매각도 균등하게)
- 굴 4채 후 궁전 1채로 업그레이드
- 은행에 굴이 없으면 건설 불가 (품절 상황 = 원작의 "주택 부족" 전략 그대로 재현)
- 건물이 하나라도 있는 그룹의 칸은 저당 불가 → 먼저 건물 매각
- 건물 매각 시 건설비의 **50%** 환급

### 5.5 케이지 (감옥)
- 들어가는 경우: "케이지로 가시오" 칸, 카드, 3연속 더블
- 단순히 10번 칸에 도착하면 "방문 중" (불이익 없음)
- 탈출 방법:
  - 🌻50 벌금 지불 후 굴림
  - 케이지 탈출권 사용
  - 더블이 나오면 탈출 & 그 숫자만큼 이동 (추가 굴림 없음)
  - 3번째 턴에도 실패하면 🌻50 지불 후 이동
- 케이지 안에서도 통행료 수금, 거래, 건설 가능

### 5.6 저당
- 저당 시 저당가 수령, 해당 땅 통행료 없음
- 해제 시 저당가 + **10%** 이자 지불
- 저당 잡힌 땅을 거래로 받으면: 즉시 해제(원금+10%) 또는 10%만 내고 저당 유지

### 5.7 거래
- 현금, 땅, 케이지 탈출권을 자유롭게 교환 (건물이 있는 땅은 거래 불가)
- 사람 → 컴퓨터 제안 가능, 컴퓨터 → 사람 제안도 가능 (수락/거절/역제안)

### 5.8 파산
- 지불 불가 시 건물 매각·저당으로 현금 마련 시도
- 그래도 부족하면 파산
  - 다른 플레이어에게 진 빚: 모든 재산을 그 플레이어에게 양도
  - 은행에 진 빚: 모든 땅은 은행으로 회수되어 경매
- 마지막까지 남은 1명이 승리

| 쉬움 | 돈이 있으면 대부분 구매, 건설은 소극적, 거래는 가끔, 경매는 정가 이하로만 |
| 보통 | 현금 보유량을 고려한 구매, 독점 시 3채까지 우선 건설, 단순한 거래 제안 |
| 어려움 | 그룹 가치 평가(주황·빨강 우선), 상대 독점 저지 입찰, 주택 품절 전략, 적극적 거래 (쉬움의 3배) |

**거래 공격성** — 어려움은 쉬움의 **3배**로 고정하고, 보통은 그 중간값을 쓴다.

| 지표 | 쉬움 (1×) | 보통 (2×) | 어려움 (3×) |
|---|---|---|---|
| 자기 턴마다 거래를 제안할 확률 | 10% | 20% | 30% |
| 한 판에서 같은 상대에게 할 수 있는 최대 제안 횟수 | 2회 | 4회 | 6회 |
| 독점을 완성하려고 추가로 얹어 주는 해바라기씨 상한 (땅 가격 대비) | 10% | 20% | 30% |

- 사람이 거절한 제안은 최소 3턴 동안 똑같이 다시 내지 않는다 (같은 제안 반복 방지)

### 6.2 의사결정 항목
- **구매**: 가격, 보유 현금, 해당 그룹 보유 현황, 상대 독점 저지 여부
- **경매**: 땅의 평가 가치까지 입찰 (난이도별 가중치)
- **건설**: 최소 안전 현금(예: 🌻200~🌻500)을 남기고 건설
- **현금 마련**: 매각 → 저당 순서, 가치 낮은 땅부터
- **케이지**: 초반엔 벌금 내고 탈출, 후반(보드에 건물 많을 때)엔 머무르기
- **거래**: 서로 독점이 완성되는 교환을 평가해 공정도 점수로 수락/거절

### 6.3 UX
- 컴퓨터 턴은 자동 진행하되, 각 행동마다 0.5~1초 지연 + 로그 표시
- "컴퓨터 턴 빨리 감기" 토글 제공
- 각 컴퓨터 햄스터는 짧은 말풍선 리액션 ("찍찍! 서울은 내 거야!")

## 25. 할 일이 없으면 자동으로 턴 넘기기 (v0.14)
사용자 요청: "주사위를 돌리고 해야 할 동작이 없으면 자동으로 넘어가게"

### 자동으로 넘어가는 조건 (모두 만족할 때)
- 주사위를 굴린 뒤이고, 더블로 다시 굴려야 하는 상황이 아님
- 구매 결정, 갚을 빚, 경매, 받은 거래 제안이 없음
- **지금 바로 지을 수 있는 건물이 없고, 해제할 수 있는 저당도 없음** (있으면 기존처럼 직접 "턴 끝내기")
- 내 땅 관리·거래·칸 정보 같은 창을 열어 두지 않음

### 화면
- "할 일이 없어서 곧 다음 차례로 넘어가요" + 진행 막대 (1.5초, 빨리 감기 시 0.5초) 후 자동으로 턴 종료
- [바로 넘기기 ✔] 기다리지 않고 바로 넘김 (스페이스바도 가능)
- [잠깐 멈추기 ✋] 이번 턴은 자동으로 넘기지 않고 기존 "턴 끝내기" 버튼으로 돌아감 (거래 등을 하고 싶을 때)
- 기다리는 동안 창을 열거나 다른 행동을 하면 자동 넘김이 취소되고, 창을 닫으면 다시 조건을 판단

## 29. 치즈 주사위 소리 · 더블 표시 개선 (v0.18)

### 29.1 치즈 소리 (치즈 주사위일 때만, 유리구슬 주사위는 기존 소리)
| 순간 | 소리 |
|---|---|
| 꾹 누르는 동안 | 손안에서 치즈를 주물주물하는 말랑한 소리 (힘이 셀수록 빨라짐) |
| 던질 때 | 휙 하고 날아가는 바람 소리 |
| 착지·통통 튐 | "말캉 통" 하는 둔탁하고 말랑한 소리 3번 (착지 → 작게 → 더 작게), 세게 던질수록 크게 |

### 29.2 "더블인데 다시 굴리지 않고 넘어간다" 신고 대응
- 조사 결과: 일반 더블은 정상 동작 ("더블! 한 번 더 굴려요" → 다시 굴림) — 시드를 맞춰 더블을 강제로 내서 재현 시험
- 원작 룰상 다시 굴리지 않는 더블: **케이지에서 더블로 탈출할 때**, **3연속 더블(케이지행)** — 화면에 이유가 안 보여 버그처럼 보였음
- 또 주사위가 비스듬해서 윗면이 결과처럼 보일 수 있었음
- 개선
  - 주사위 아래에 결과 글자 표시: "🎲 3 + 3 = 6 · 더블!"
  - 다시 굴리지 않는 더블이면 이유 표시: "케이지 탈출! (탈출할 땐 한 번 더 굴리지 않아요)" / "3연속 더블 → 케이지행"
  - 주사위 기울기 줄임 (-24°/30° → -15°/20°) — 정면(결과) 면이 더 잘 보이게
